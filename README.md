## CN2线路是什么？先搞清楚这个概念

CN2是中国电信下一代互联网（ChinaNet Next Carrying Network，简称CNC）旗下的高端骨干网络。相比普通的163骨干网，CN2线路的路由更短、跳数更少、拥堵更少，用一句大白话说就是：**同样从美国到你家，CN2走的是快车道，普通线路走的是省道绕村路。**

CN2线路还分两种档次：

### CN2 GT（Global Transit）

GT是CN2里的入门版。电信出口是CN2，但回程不一定走CN2，可能绕回普通163网络。高峰期依然会有拥堵，适合预算有限的用户。

### CN2 GIA（Global Internet Access）

GIA是CN2的旗舰档，**双向全程走CN2线路**，来回都不经过普通163骨干，路由稳定，晚高峰也很少掉速。搬瓦工之所以能卖到几十美元一个月还有人买，靠的就是这条线路。

不止电信用户能受益——移动走CMI、联通走AS9929，也是同类逻辑的中国优化路由。三网用户如果要都照顾到，就得看服务商是否支持"三网CN2 GIA"或者"三网优化"。

## 为什么CN2 GIA这么贵，还是有人抢着买？

这个问题很好回答：**带宽资源有限，优质线路总是稀缺的。**

CN2 GIA的物理带宽容量本来就比163骨干小，中国电信又把它卖给多家服务商，最终分配到每台VPS上的带宽资源自然珍贵。这也是为什么走CN2 GIA的机器往往限速在1Gbps甚至以下，但延迟和稳定性远超走大带宽但拥挤的普通线路。

实际使用感受上，**CN2 GIA的优势在三个场景里特别明显**：

1. **建站**：国内用户打开网站速度快，跳出率低，对SEO也友好
2. **远程工作/科学上网**：SSH操作流畅，延迟低，丢包少
3. **视频/直播**：上行带宽稳定，推流不卡顿

## CN2线路的几个常见误区

说到这里顺便帮大家排一下雷，这些坑很多人踩过：

**误区一："CN2就等于CN2 GIA"**

不是的。CN2 GT和CN2 GIA差别很大，晚高峰体验完全不同。买之前一定要确认是不是双程GIA，不然容易花了GIA的钱买到GT的体验。

**误区二："香港VPS=低延迟=快"**

香港节点延迟是低，但不是所有香港VPS都走CN2 GIA。部分便宜香港VPS走的是CMI或者NTT，甚至普通BGP，晚高峰同样拥堵。

**误区三："带宽越大越好"**

走CN2 GIA的线路，10Gbps共享带宽比走普通163的100Gbps带宽在国内的实际访问速度要好得多。带宽数字只是参考，线路质量才是核心。

**误区四："IP被封了没法用"**

DMIT提供免费换IP政策（仅限IP被GFW封锁的情况），这一点比不少竞争对手要厚道。另外购买后3天内、使用流量不超过30GB的情况下可以全额退款，入门门槛相对宽松。
